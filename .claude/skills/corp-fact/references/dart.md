# DART 사업보고서 원문 추출 절차

한국 상장사 공시 원문을 여는 방법이다. DART 웹 화면은 자바스크립트로 그려지고 뷰어는 접수번호 없이 열리지 않으므로, WebFetch로 `dart.fss.or.kr`를 그냥 요청하면 목차만 보이거나 빈 화면이 온다. **Bash의 curl로 아래 세 엔드포인트를 순서대로 호출한다.** 2026-09-16에 기아(000270)와 LG전자(066570)로 검증한 경로다.

공통 주의사항이다.

- 세 요청 모두 **`Referer` 헤더가 필요하다.** 없으면 빈 응답이나 리다이렉트가 온다.
- 간헐적으로 `SSL_ERROR_SYSCALL`이 난다. `--retry 2 --retry-delay 2`를 붙이고, 실패하면 잠시 뒤 한 번 더 시도한다.
- OpenDART API(`opendart.fss.or.kr`)는 인증키가 필요하므로 쓰지 않는다. 아래 경로는 공개 화면과 같은 엔드포인트다.
- 중간 산출물은 스크래치패드 디렉토리에 저장한다. 저장소에 커밋하지 않는다.

## 1단계. 종목코드로 정기공시 목록과 접수번호(rcpNo) 얻기

`textCrpNm`에 **회사명이 아니라 6자리 종목코드**를 넣는 것이 요령이다. 회사명으로는 빈 결과가 오는 경우가 있다.

```bash
S=<스크래치패드 경로>
curl -sS -m 40 --retry 2 --retry-delay 2 \
  "https://dart.fss.or.kr/dsab007/detailSearch.ax" \
  -X POST \
  --data-urlencode "currentPage=1" \
  --data-urlencode "maxResults=15" \
  --data-urlencode "textCrpNm=000270" \
  --data-urlencode "publicType=A001" \
  -H "Referer: https://dart.fss.or.kr/dsab007/main.do" \
  -o $S/list.html
```

`publicType` 값은 다음과 같다. 셋 다 검증했다.

| 값 | 보고서 |
| --- | --- |
| `A001` | 사업보고서 |
| `A002` | 반기보고서 |
| `A003` | 분기보고서 |

목록 파싱은 다음과 같이 한다. 보고서명, 제출일, 접수번호가 한 줄로 나온다.

```bash
python3 - <<'PY'
import re, html
s = open(f'{S}/list.html', encoding='utf-8', errors='replace').read()
for r in re.split(r'<tr[^>]*>', s):
    rc = re.search(r'rcpNo=(\d+)', r)
    if not rc:
        continue
    txt = re.sub(r'<[^>]+>', ' ', r)
    txt = re.sub(r'\s+', ' ', html.unescape(txt)).strip()
    print(rc.group(1), '|', txt[:160])
PY
```

출력 예시다.

```
20260916000427 | 1 유 기아 [기재정정] 반기보고서 (2026.06) 기아 2026.09.16
20260814003932 | 2 유 기아 반기보고서 (2026.06) 기아 2026.08.14 정
```

**`[기재정정]`이 붙은 더 최근 건이 있으면 그것을 쓴다.** 원본에는 "본 보고서 제출 후 정정신고가 있으니 관련 보고서를 참조하시기 바람" 비고가 붙는다. 위 예시에서 옳은 선택은 `20260916000427`이다. 정정본을 놓치고 원본을 인용하면 이미 바뀐 수치를 확정 사실로 쓰게 된다.

## 2단계. 접수번호로 문서 트리와 섹션 파라미터 얻기

```bash
curl -sS -m 40 --retry 2 --retry-delay 2 \
  "https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20260312001224" \
  -H "Referer: https://dart.fss.or.kr/dsab007/main.do" \
  -o $S/main.html
```

이 HTML 안에 목차가 자바스크립트 객체로 들어 있다. 한 노드는 다음 형태다.

```javascript
var node2 = {};
node2['text'] = "4. 매출 및 수주상황";
node2['rcpNo'] = "20260312001224";
node2['dcmNo'] = "11116515";
node2['eleId'] = "13";
node2['offset'] = "203864";
node2['length'] = "20377";
node2['dtd'] = "dart4.xsd";
```

전체 목차를 표로 뽑는다.

```bash
python3 - <<'PY'
import re
s = open(f'{S}/main.html', encoding='utf-8', errors='replace').read()
for b in re.split(r"var node\d+ = \{\};", s):
    def g(k):
        m = re.search(r"\['" + k + r"'\]\s*=\s*\"([^\"]*)\"", b)
        return m.group(1) if m else ''
    t = g('text')
    if t and g('dcmNo'):
        print('\t'.join([t, g('dcmNo'), g('eleId'), g('offset'), g('length'), g('dtd')]))
PY
```

`eleId`와 목차 번호가 일치하지 않는 문서가 있으므로 **텍스트로 섹션을 찾고 그 줄의 파라미터를 그대로 쓴다.** 번호를 추측해 넣지 않는다.

## 3단계. 섹션 본문 내려받아 텍스트로 변환

```bash
curl -sS -m 60 --retry 2 --retry-delay 2 \
  "https://dart.fss.or.kr/report/viewer.do?rcpNo=20260312001224&dcmNo=11116515&eleId=29&offset=649069&length=40706&dtd=dart4.xsd" \
  -H "Referer: https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20260312001224" \
  -o $S/sec_29.html
```

표가 많으므로 셀 구분을 살려 변환한다.

```bash
python3 - <<'PY'
import re, html, glob
for f in sorted(glob.glob(f'{S}/sec_*.html')):
    s = open(f, encoding='utf-8', errors='replace').read()
    s = re.sub(r'<(script|style)[^>]*>.*?</\1>', '', s, flags=re.S)
    s = re.sub(r'</t[dh]>', '\t', s)
    s = re.sub(r'</tr>', '\n', s)
    s = re.sub(r'<br\s*/?>', '\n', s)
    s = re.sub(r'<[^>]+>', '', s)
    s = html.unescape(s)
    s = re.sub(r'[ \t]*\t[ \t]*', '\t', s)
    s = re.sub(r'\n{3,}', '\n\n', s)
    open(f.replace('.html', '.txt'), 'w').write(s.strip())
    print(f.replace('.html', '.txt'))
PY
```

## 섹션별로 무엇이 나오는가

기아 제82기(2025) 사업보고서에서 실제로 확인한 내용이다. 회사마다 목차 번호는 다르지만 항목 이름은 표준 서식이므로 텍스트로 찾으면 된다.

| 섹션 | 얻을 수 있는 것 |
| --- | --- |
| `II. 1. 사업의 개요` | **보고부문 구성**(단일 부문인지 여부와 그 근거), 주요 제품과 차종·모델명, 생산능력·실적·가동률 요약, 국내외 공장 위치, 연간 실적 요약 |
| `II. 2. 주요 제품 및 서비스` | 제품군 정의, 가격 정보 |
| `II. 3. 원재료 및 생산설비` | **공장별 매입액·매입 비중·주요 매입처**(계열사 의존도가 여기서 드러난다), 원자재 가격 3개년 추이와 가격 기준(PLATTS·LME·ICIS 등), **공장별 생산능력·생산실적·가동률 3개년** |
| `II. 4. 매출 및 수주상황` | **지역별 총매출·내부매출·순매출**, **별도기준 품목별 내수·수출 매출 3개년**, 판매경로와 판매방법, 위탁생산 관계, **판매전략**(회사가 밝힌 연도별 지역 전략과 시장 진단) |
| `II. 5. 위험관리 및 파생거래` | 신용·유동성·시장(환·이자율) 위험과 **회사의 헤지 전략** |
| `연결재무제표 주석 중 영업부문` | 지역별 또는 부문별 매출과 비유동자산. 판매법인 단위(예: KUS)까지 쪼개진 경우가 있다 |
| `주석 특수관계자` | 계열사 거래 금액 전체 |
| `주석 충당부채` | 판매보증충당부채 설정·환입 |
| `IV. 3. 재무상태 및 영업실적` | **경영진이 직접 쓴 실적 설명**. 매출원가율·판관비율의 증감과 그 원인, ASP, 연결 매출대수, 요약 재무상태표와 손익계산서 |
| `VII. 주주에 관한 사항` | **최대주주와 특수관계인 지분율**(기초·기말), 모회사의 최대주주까지 |
| `VIII. 임원 및 직원 등의 현황` | 인원, 평균근속, 보수 |
| `XI. 3. 제재 등과 관련된 사항` | 소송·제재·리콜 |

## 공시를 읽을 때 자주 걸리는 함정

1. **보고부문이 하나인 회사가 있다.** "하나의 보고부문으로 구성됩니다"라고 적혀 있으면 부문별 매출·이익 대조 분석이 구조적으로 불가능하다. 억지로 부문을 만들지 말고, 공시가 실제로 제공하는 분해 축(지역, 품목, 공장)으로 대체한다.
2. **지역별 매출의 기준이 IR과 다르다.** 주석의 "본사 소재지 국가"는 **판매 주체의 소재지** 기준이어서 본사의 비계열 수출이 포함된다. IR 자료의 지역별 비중은 보통 **목적지 시장** 기준이다. 기아의 경우 국내 비중이 공시 26.3% 대 IR 11.3%로 갈렸다. 둘을 섞으면 안 된다.
3. **판매대수 기준이 여러 개다.** 글로벌 도매판매(IR), 연결 매출대수(공시 IV.3), 연결 생산실적(공시 II.3)이 모두 다르다. 비연결 법인과 CKD 제외 여부가 원인인데 공시가 대조표를 주지 않는 경우가 많다. 어느 기준인지 밝히고, 차이의 원인을 확인 못 했으면 **(확인 필요)** 로 남긴다.
4. **별도기준과 연결기준을 구분한다.** 품목별 매출은 보통 별도기준으로만 공시된다. 연결 매출과 비중을 섞어 계산하지 않는다.
5. **주주총회 승인 전 재무제표일 수 있다.** 사업보고서에 "주주총회 승인 전 연결재무제표입니다"라는 주기가 붙으면 그 사실을 노트에 적는다.
6. **지분율이 주식수 변동 없이 바뀐다.** 자기주식 소각으로 발행주식총수가 줄면 주식수가 그대로인데 지분율이 오른다. 원인을 `I. 4. 주식의 총수 등`에서 확인하지 않았으면 추정하지 말고 **(확인 필요)** 로 둔다.
7. **위험요소가 별도 장으로 없는 경우가 있다.** 관세·수요 같은 사업위험이 `II. 5`가 아니라 `II. 4` 판매전략이나 `IV. 3` 실적 설명에 흩어져 있다. `II. 5`가 금융위험만 다루면 그 사실을 적고 다른 장에서 찾는다.

## 미국 상장사

DART 대신 SEC EDGAR를 쓴다. `https://www.sec.gov/Archives/edgar/data/{CIK}/...` 경로의 10-K·10-Q 문서는 WebFetch로 직접 열린다. 접근 방식이 달라 이 문서의 절차는 적용되지 않는다.
