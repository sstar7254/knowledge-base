- 엔비디아는 왜 어떤 것은 사고 어떤 것은 빌리고 어떤 것은 열어주는가 — 엔비디아 딜의 형식(인수/라이선스/CB/지분/표준개방/자본공여)이 위협의 거리와 규제 노출도로 결정된다는 렌즈. 그록 자산·라이선스 vs 허깅페이스 정식인수의 대비가 핵심 증거, AMD 워런트 3.2억 주가 대조군
