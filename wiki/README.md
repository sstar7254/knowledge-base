# wiki — 연결 레이어

`raw/`의 불변 원본 위에서, 노트를 **가로지르는** 개념·맥락을 종합하는 곳.
여기 있는 모든 페이지는 `raw/`로 거슬러 올라갈 수 있어야 하며, 원본으로부터 다시 만들어낼 수 있어야 한다.
운영 규칙은 [`../schema/CLAUDE.md`](../schema/CLAUDE.md) 참고.

## 종합 페이지 (Synthesis)

- [[중동-에너지-호르무즈]] — 중동 지정학 → 유가 → 한국 산업(정유·조선·방산)으로 이어지는 인과 사슬. `news-scrap`, `strategic-thinking`, `concepts-vault/Geopolitics`, `stock-market`를 가로지름.

## Maps of Content (예정)

raw가 쌓이는 대로 아래 MOC를 추가/갱신한다.

- 미중 패권 경쟁 — `raw/concepts-vault/Geopolitics/Index/미중 패권 경쟁.md`을 허브로 확장 예정
- AI 사이클 — `raw/stock-market/01. AI_Semiconductor_Robotics/` 종합 예정
- 스타트업·VC 계약 구조 — `raw/concepts-vault/Venture Capital/` + `raw/startup-innovation/` 연결 예정

## 유지보수 메모

- raw 노트가 추가·이동되면 관련 페이지의 링크와 `updated`를 갱신한다.
- 깨진 위키링크는 즉시 고친다.
- 새 페이지는 반드시 이 허브에서 링크한다.
