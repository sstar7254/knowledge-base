# PRS (Price Return Swap, 주가수익스와프)

> 특정 주식의 가격 변동분(배당 제외)만을 교환하는 장외 파생상품으로, 대주주가 지분을 매각하지 않고 주가 하락 위험을 헤지하거나 경제적 소유권을 분리할 때 활용

## 상세 설명

Total Return Swap(TRS)의 변형으로, TRS가 배당을 포함한 총수익을 교환하는 반면 PRS는 **주가 변동분(시세차익/차손)만** 교환한다.

**기본 구조:**
- PRS 매도자(헤지 수요자): 주가 상승 시 이익을 상대방에게 지급, 주가 하락 시 이익을 수령 → 하락 위험 전가
- PRS 매수자(증권사 등): 주가 상승 시 이익을 수령, 주가 하락 시 손실 부담 → 고정·변동 금리 수취
- 기준자산: 특정 주식 또는 주가지수

**주요 활용 사례:**
- 대주주가 주식 매각 없이 주가 하락 리스크를 헤지
- 증권사가 대주주와 PRS 계약 체결 후 해당 주식의 경제적 소유권(Economic Ownership)을 사실상 이전
- 블록딜(Block Deal) 전 시장 충격을 완충하는 구조로 활용

**회계·공시 이슈:**
- PRS를 통해 대주주 지분 구조가 형식과 실질이 괴리될 수 있어 회계 처리 쟁점 발생
- 파생상품 부채 인식(공정가치 평가), 지배력 판단 등이 핵심 논점
- 공시 의무 회피 수단으로 악용될 소지가 있어 규제 당국의 모니터링 대상
