**2. 자산 별 투자 매력도가 금융시장에 미치는 영향력**

- 연착륙

: 주식시작 상승, 금리인하 지연 => 빅테크 유리

: 경기 호황과 인플레이션 지속 우려 => 채권 악재

: 인플레이션 우려로 금 가격이 상승할 수 있으나 매력도가 낮아져 금 상승세 제한

- 경기침체

: 주식시장 하락 => 빅테크 유리

: 경기 둔화, 인플레이션 둔과 => 채권 유리

: 중장기간 인플레이션 지속 예상, 금 가격 하락 가능성은 낮음, 리밸런싱 관점에서 금 수요 증가

따라서, 포트폴리오는 주식 매수 + 채권, 금 매수

- 달러

1) 최근 **원화의 움직임은 오랜 기간 위안화/엔화 움직임에 연동**

2) 최근 달러 가격 변동성 발생 요인

: 경기침체 여부 -> 미국 금리 영향 -> 엔캐리 트레이드 심화 -> 달러 변동성 증가

: 미국 금리 하락 -> _엔캐리 트레이드 우려(청산) 강화_ -> 엔화 강세 & 달러 하락

: 미국 금리 상승 -> _엔캐리 트레이드 우려(청산) 약화_ -> 엔화 약세 & 달러 강세

- 엔캐리 트레이드 = 저금리인 엔화를 빌려 고금리인 달러에 투자

엔캐리 트레이드 공포는 달러/엔 환율이 140엔을 밑돌 때 심화

=> **미국 경기 둔화** 예상 시 엔캐리 트레이드 우려로 인해 **엔화 강세 & 원화 강세**
